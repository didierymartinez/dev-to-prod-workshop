# Fase 0 — Preparación

> **Meta de la fase:** Dejar tu computador listo para todo el taller, sin importar si usas Windows, macOS o Linux. Al terminar tendrás cada herramienta instalada **y verificada**, y conocerás los pocos comandos de terminal que usaremos.

No escribirás código todavía. Esta fase evita el problema más común y frustrante: empezar a aprender y quedarte atascado porque algo no estaba bien instalado.

## ¿Qué vamos a instalar y para qué?

No instales nada aún — lo harás guiado en la Lección 2. Pero esto es lo que viene y por qué:

| Herramienta | ¿Para qué sirve? | ¿Desde qué fase? |
|---|---|---|
| **Git** | Guardar la historia de tu código | Fase 1 |
| **Visual Studio Code** | El editor donde escribirás todo | Fase 1 |
| **.NET SDK 8** | Crear y compilar tus programas | Fase 2 |
| **Postman** | Probar APIs sin escribir código | Fase 3 |
| **Docker Desktop** | Empacar tu app en una "caja" portable | Fase 6 |
| **Azure CLI** | Manejar servidores en la nube | Fase 9 |

> 💡 Las primeras lecciones solo necesitan Git y VS Code. Si quieres, puedes instalar Docker y Azure CLI más adelante, justo cuando lleguen sus fases. La Lección 2 te lo indica.
