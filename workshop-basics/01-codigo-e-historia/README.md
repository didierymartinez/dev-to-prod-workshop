# Fase 1 — El código y su historia

> **Meta de la fase:** Aprender a guardar tu trabajo con **memoria**: qué cambió, cuándo y por qué. Vas a conocer Git (la herramienta que usan todos los equipos de software del mundo) y GitHub (donde vive el código en internet).

Todavía no programaremos en serio. Primero aprendemos a **no perder el trabajo** y a colaborar — porque eso lo necesitarás desde la primera línea de código que escribas en la Fase 2.

---

## ¿Por qué Git antes que programar?

Porque en el trabajo real **nunca** se escribe código sin versionarlo. Aprender a programar sin Git es como aprender a conducir sin frenos: funciona hasta que necesitas parar y no puedes. Mejor aprenderlo desde el principio, con ejemplos sencillos, antes de que el código se complique.
