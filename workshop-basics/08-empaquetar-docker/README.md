# Fase 8 — Empaquetar con Docker

> **Meta de la fase:** Empacar tu aplicación en una **imagen de Docker**: una "caja" que incluye tu API con todo lo que necesita para correr. Esa caja funcionará **idéntica** en tu máquina, en la de un compañero y en un servidor — el fin definitivo del *"en mi máquina funciona"*.

---

## ¿No usamos ya Docker?

Sí, en la Fase 6 usaste Docker para **correr** una base de datos que otros empaquetaron. Ahora darás el paso grande: **empaquetar tu propia aplicación** en una imagen, y orquestar tu API junto a su base de datos con un solo comando. Es la preparación directa para llevarla a un servidor (Fases 9-11).
