# Fase 3 — Cómo se comunican los programas

> **Meta de la fase:** Entender **HTTP**, el idioma con el que los programas se hablan por internet. Y entenderlo de la mejor forma posible: **usando** una API que ya existe, antes de construir la tuya.

No escribirás código de servidor en esta fase. Vas a *consumir* datos de internet y observar cómo viajan, para que cuando construyas tu propia API (Fase 4) sepas exactamente qué estás creando y por qué.

---

## ¿Por qué entender HTTP antes de construir una API?

Porque una **API es, en el fondo, un programa que habla HTTP**. Si no entiendes qué es una petición, una respuesta, un método o un código de estado, construir una API es como armar un teléfono sin saber qué es una llamada. Primero el concepto; luego la herramienta.
